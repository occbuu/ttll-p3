# Cách lấy DOI cho repo **code**

Repo này chỉ chứa script, notebook và output phân tích. Không upload bản thảo.

1. Repo GitHub **Public**: https://github.com/occbuu/ttll-p3
2. Zenodo → GitHub → bật webhook cho repo
3. GitHub Releases → tag `v1.0.0` (hoặc bản mới) → Publish
4. Zenodo mint DOI; dán DOI vào `CITATION.cff`

Không đưa vào git: PDF/Word/TeX, `QData_*.xlsx`, tọa độ hộ, file `.pbf`, raster GHSL, PCI gốc.
