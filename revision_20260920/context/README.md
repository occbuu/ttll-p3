# Context layers

`wards.geojson` is copied from the project archive `OpenData/ThuDucCity_ward.geojson`; the Truong Tho feature is selected by its English name. Original provider, legal boundary date and redistribution licence have not been independently established from available metadata. Confirm these before public release of this layer. It is a contextual outline only and is not used for distances or sample inclusion.

`metro.geojson` is copied from `OpenData/osm_layers/metro.geojson`, retaining OSM object IDs and tags. Only `ref=L1` features are drawn. It is an undated context alignment, not a certified 2023 operating network. OSM attribution and ODbL terms apply.

Both file hashes are recorded in `analysis/map_audit.json`. The 2023 street graph and bus points themselves come from the hash-checked historical PBF, not these context layers.
